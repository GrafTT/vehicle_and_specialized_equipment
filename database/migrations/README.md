# Правила работы с миграциями

1. Имена файлов: YYYYMMDD_<номер>_<название_подсистемы>_<описание>.sql
   Пример: 20261123_001_subsystem_a_create_vehicles_table.sql
2. Каждая миграция должна содержать как Up (создание), так и Down (откат) скрипты.
3. Таблицы, создаваемые в миграции, принадлежат только одной подсистеме.
